## Why this list

Most "skill catalogs" are dumps. This one is curated: we score every entry on a two-axis rubric — Craft (does the skill spec itself well?) and Adoption (is it maintained, documented, licensed permissively, used by others?). The composite is a harmonic mean — a skill is only as good as its weakest axis. See the [methodology →](https://humangarden.ai/about/).

The list updates **every 24 hours** from public sources (anthropics/skills, openai/skills, skills.sh, skillsmp, GitHub code search). New skills appear here within a day of release.

## How this list is maintained

This README is **auto-generated daily** from the [humangarden.ai](https://humangarden.ai) database. The source-of-truth lives in a structured SQLite store; this file is one rendered view of it.

### Two-axis scoring

- **Craft (D1–D5):** trigger clarity · output specificity · scope precision · self-containment · reusability. Applied only to SKILL.md-format skills.
- **Adoption (A1–A5):** maintenance signal · documentation depth · license permissiveness · adoption momentum · authorship credibility. Applied to everything.
- **Composite:** harmonic mean of both axes when both apply; Adoption alone when the entry is a regular repo rather than a SKILL.md skill.

### Sources we scrape

- `github.com/anthropics/skills` and `github.com/openai/skills` (official)
- [skills.sh](https://skills.sh), [skillsmp.com](https://skillsmp.com) (curated marketplaces)
- GitHub code search for `SKILL.md` (wild)
- Top owner repos of builders we profile editorially (treated as Adoption-only entries)
